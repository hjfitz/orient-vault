# Meeting debrief

Raw notes in, two paste-ready blocks out: the occurrence's pen-glyph Notes lines, and the
open loops they created. The output is an addition — existing lines are never rewritten.

  id="meeting-debrief"

{{context}}

## Ask
1. Notes — the block to paste under that occurrence's "### Notes" heading. Every line starts "- ✍️ " exactly, past tense, one point per line, no sub-headings. It is an addition: leave the lines already there alone.
2. Open loops — per person, the checkbox lines to add under "**I owe**" or "**Owed to me**" on their note, each as "- [ ] thing (date)".
3. Anything that is neither a note nor a loop and should simply be dropped — list it so I can confirm.
Keep my wording where it is already clear, and never summarise away a name, a number or a date.
Return markdown, under 300 words.`}
