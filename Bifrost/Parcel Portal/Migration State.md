## What this is
A web portal for TCA (Yusen US, FedEx, US→US/CA) that imports Manhattan SCALE CSVs over SFTP, validates them with partial import, labels through Selector, manifests, and exports the day's shipments back to Manhattan. See [[Parcel Portal/Overview|Overview]].

> SUPERSEDED 2026-11-02 — Harry: the Parcel Portal isn't part of the Merak (MKP) work, so Jira is no longer kept in step. This ledger is the only tracker; the `Jira` column below is history.

**Jira mirrors this ledger.** Epic [MKP-2](https://globalfreight.atlassian.net/browse/MKP-2) carries the programme context. Each unit is one MKP task (the `Jira` column), and each gate is a `[Gate]` task linked `Blocks` to the work it holds up. Keep them in step in the same session as any change here:
- a unit starts: its task goes to In Progress;
- a unit merges: its task goes to Done, with the PR link in a comment;
- a gate clears: its `[Gate]` task goes to Done, with the answer in a comment;
- a new blocker appears: add a gate here and a `[Gate]` task in Jira, linked to what it blocks;
- scope, a dependency or a decision changes: update the task description, and the epic if the programme's shape changed.

**The invariants every unit holds:**
- **No cross-tenant data, ever.** Every row carries `tenant_id`, every query filters on it, and a second dummy tenant's data must stay invisible in every test.
- **A bad row never blocks a good one.** Format errors reject the file. Data errors flag the row and import the rest.
- **Validate in the app first.** Selector's `ValidateShipment` is the last resort, because its errors are sometimes just "error".
- **Never log a payload, address or credential.** Log identifiers only.
- **Nothing installed on the customer's machines.**

## Scar tissue
- **The first push to a template-derived repo's `main` deploys the template.** parcel-portal's initial push ran svc-template's `ui deploy` (its `root.hcl` still said `repo = "svc-template"`). It was force-cancelled during the image build, before Terraform. Change `root.hcl` before anything reaches `main`, and push the baseline to a branch first. Found 2026-10-28.
- **Cloud Run serves HTTP only.** The SFTP command runs on a MIG behind a TCP load balancer, as sftp-connector's Go host does.
- **Health-check the container, not port 22.** On COS, the OS's own sshd answers TCP:22 for 20–30 s while an instance boots, so a TCP check passes a host that isn't serving yet. Probe the container's HTTP `/healthz` on 8080, and allow the load balancer's probe ranges in the firewall (sftp-connector #364 and #365).
- **Excel destroys tracking numbers.** DC's export shows `1.5501E+13`. Write them as quoted text.
- **Selector's CSV import fails the whole file on one bad line.** That's why the portal does partial import.
- **Name the repo in an ilg-merak repo's `root.hcl`.** `basename(get_repo_root())` is `workspace` in CI, so a template-derived repo would share svc-template's state.
- **ship.gfsdeliver.com carries a live account.** Look only.
- **oasdiff treats any change to a response `enum` as breaking**, whether that's adding a value or switching to `x-extensible-enum`. Declare fields that may grow as `x-extensible-enum` from their first version, as the customer API does. Found 2026-11-03 (#80).
