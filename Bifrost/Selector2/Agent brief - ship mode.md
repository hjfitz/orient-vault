## Fixed decisions (do not reopen)
One multi-tenant DB; account = tenant; every row has `tenant_id`; no unscoped query (repository functions take a tenant scope). Accounts have a login (argon2id), role `god` | `standard`, many hashed revocable API keys (shown once). `god` sees every tenant, `standard` only its own. Five label operations only: ProcessShipment(s), ValidateShipments, DeleteShipments, CommitShipGroup, CommitShipments, over SOAP (wire-compatible with CSS; the credentials are the BODY element `AuthenticationDetails`, not a header) and REST v1 (selector-rest-proxy parity) then REST v2 (terse). Only the 12 proxy carriers (royalmail, ups, coll8, fedex, dpdeu, amazon-sfp, amazon, bjs, inpost, ocs, exelot, veho). A repeated (tenant, reference) returns the existing live shipment. Mock proxies are public (`allUsers`), selector2 still sends a Cloud Run ID token in `X-Serverless-Authorization` (as carrier-playground's mock-kit does toward its upstreams). Both selector2 services are public with app-level auth. No Firebird events. All data synthetic.
