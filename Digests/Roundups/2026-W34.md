# Fuse Week Roundup — 2026-W34 (w/c 17 August 2026)

## Approved post

```
*Fuse this week* — w/c 17 August

Big week — our first live Shopify customer, and a few things still being chased down underneath it.

*🚀 Product progress*
• The Work Order Confirmation / Finished Good Receipt workstream reached code-complete this week and started entering QA — support will soon be able to see and retry failures across the whole work-order family, not just sales orders.
• RGA (returns) confirmation mapping entered QA.
• A public developer portal and a full "Try it"-console API reference shipped for the Fuse API — external integrators can now explore and test every v2 endpoint themselves.

*⚙️ Engineering*
• Circuit-breaker/retry logic was pulled out of the SNAP-specific package into a shared resilience package, so any Fuse service — starting with the Shopify connector — can get the same protection without depending on a package named for a different system.
• Added per-host rate limiting and circuit breakers in front of SNAP, so a struggling SNAP host can no longer be hammered into a worse state by Fuse's own traffic.
• Dedupe and the collector were both hardened — database retries and a health check that reflects real reachability, plus backoff on message delivery — cutting the odds of a false-healthy state or a dropped message under load.
• The Retry Queue was extended to cover the full work-order/FGR/RGA confirmation family, giving support one-click visibility into failures that were previously invisible.

*📈 Reliability & operations*
• SNAP (the WMS) had a genuine ~5-hour vendor outage on Tuesday; the response held up well — the affected orders were identified, cleanly redriven with zero duplicates, and nothing was lost.
• One formal incident this week: a Saira Skin order got stuck re-announcing to Shopify for 36 minutes (a missing warehouse data field); fixed same day, with a durable fix now tracked.
• Prod availability on the instrumented gateway/connector surface came in at 97.25% this week, down from 99.0% — entirely the retry-exhaustion tail of Tuesday's SNAP outage, not a new regression. Dev held steady.
• **Open:** Saira Skin's Shopify order intake has been silently collecting zero orders since Tuesday afternoon, traced to a connector configuration change. A fix is in progress — the longer it stays open, the more of the missed backlog becomes unrecoverable.
• Also found this week: Saira Skin has been silently throttled by Shopify since Monday, with no monitor catching it. Two fixes are written and in review.

*💡 Highlights*
• Matt rebuilt the Shopify connector's bulk-ingest pipeline this week onto a leaner, watermark-based design, replacing the old per-shop polling state machine — already rolling out live behind a flag.
• Nylah wired connector/storefront/use-case data and a per-customer broadcast opt-in flag end-to-end through types, the config API and the UI, giving Smart Routing the data it needs to make routing decisions.

*🤝 Cross-team & business*
• Saira Skin went live this week as Fuse's first-ever Shopify production customer, alongside onboarding Purdy & Figg (ILG's biggest customer this year) — both under real time pressure. Peter Liu sent the team a personal thank-you, and leadership is now looking at tightening the onboarding process so this doesn't turn into firefighting again.
• Spent much of the week walking ILG's James Godsell through Fuse's mapping tools to fix Purdy & Figg's size-tag formatting, ending with a written usage guide for their team.
• Onboarding tracking moved off Jira onto a shared "Go-Live Ledger" this week, so customer volumes and scope get reviewed upfront instead of being discovered mid-onboarding.

*🔭 Up next*
• Get the Work Order / Finished Good Receipt confirmation family through QA and closed out.
• Get RGA (returns) confirmations verified end-to-end — needs a human-run test return through the SNAP UI.
• Continue Smart Routing of confirmations, and land the Shopify throttle-protection fixes now in review.

*📊 At a glance*
• 57 PRs merged
• 11 Jira items done, 31 progressed
• 1 new incident (closed same day)
• 16,412 API requests through the instrumented gateway in prod
• 5,660 records processed in prod (↑117% vs prior week)
• 1 CVE wave cleared

Thanks for a heavy week, team — have a good weekend.
```
