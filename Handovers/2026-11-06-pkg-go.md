## Gotchas
- **A new repo's first workflow PRs get no runs** until the workflow files are on `main` (memory `reference_new_repo_workflows_need_default_branch`).
- **`actions/checkout` persists `github.token`, which outranks an app token in the remote URL**, so the push gets a 403. Use `persist-credentials: false` (memory `reference_checkout_persisted_token_beats_url_token`).
- **pkg-go reads npm with `github.token`**, so every `@gfs-bifrost` package a generator installs, transitive ones included, needs Read for pkg-go under *Manage Actions access*. Today that's audit, snap, types and resilience.
- **`gorelease` treats a const's new value as incompatible**, so `release-version.sh` ignores the `SourceVersion` change. It also refuses an unclean tree, untracked files included.
- **go-jsonschema:**
  - It emits nothing for a root union, so split it per arm.
  - Drop `additionalProperties`, or nested types get a stray field.
  - Strip `omitempty` so `[]` round-trips.
  - Zod's date preprocess becomes `interface{}` unless overridden to `types.Date`.
- **Real Snap:**
  - It returns 406 without `Accept: application/json`.
  - It sends kit `Qty` as `1.0`, so `UseNumber` needs the float decode hook.
  - It returns 400 on `Owner eq` on list routes.
- **Renovate in pkg-go:** it now skips `*/tools/*/package.json` (renovate-runner#7). It still bumps anything else.
- **zsh:** it doesn't word-split `$var` in `for`/`set --`; pass arguments explicitly.
- **The comment-density hook** blocks any commit that adds a multi-line comment; collapse it to one line.
