## Gotchas
- **Comment-density hook blocks pushes and commits** that add multi-line comment blocks: collapse each to ONE line (do the edit in its own command, then commit/push in another; the hook inspects the command before it runs).
- **Merging main into a branch:** shared wiring files conflict (`bootstrap/containers/app.module.ts`, `models/tokens.ts`, `observability/messages.ts`, `README.md`, `create-app.ts`, lockfile): keep both sides; run `pnpm install --lockfile-only` if the lockfile disagrees; run `biome check --write` then the full tests.
- **Postgres tests:** `docker run -d --name <unique> -e POSTGRES_PASSWORD=pw -p <unique port>:5432 postgres:17`, then `PGHOST=localhost PGPORT=<port> PGUSER=postgres PGPASSWORD=pw mise x node@24.7.0 pnpm@10.34.7 -- pnpm run test`. Remove the container after.
- **zsh does not word-split variables:** write helpers as functions (`wp(){ python3 "$HOME/.claude/waypoint/wp.py" "$@"; }`), not string variables.
- **GitHub API rate limit** is shared (5,000/hour); check `gh api rate_limit` before bursts.
- **XFF hop count** was verified black-box on the API and the UI on dev (12 bad logins with spoofed `X-Forwarded-For` end in 429): the last entry is Google's.
- **Live SOAP probe shape:** SOAPAction is the bare operation name in quotes (`"DailyShipQuery"`), wrapper `RequestedDailyQuery`, namespace `http://justshoutgfs.com/Client/Ship/v5/`, credentials in the body `AuthenticationDetails` (UserID = account username, UserPassword = one of its API keys).
- **Terraform local plan technique:** copy `iac/` to a scratch dir, swap the backend to `local`, `TERRAGRUNT_TFPATH=~/.local/share/mise/installs/terraform/1.14.9/terraform`, terragrunt 0.50.8; never apply from a laptop; CI applies on merge to main.
