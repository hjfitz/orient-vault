# selector — design language

The system has one rendered surface, [[client4]]. CSS has no UI.

- **No recorded design language.** Client4 is a Delphi 7 VCL app built on DevExpress grids, with a skin config (`GFSClient4.skincfg`). Each dialog is its own `fm*.pas` form.
- **The reader is warehouse staff at a PC**, shipping a day's orders. Per-carrier options and customs open as modal dialogs from the shipment.
- **No new UI is planned here.** Selector is being replaced through Merak, so screen changes stay limited to what carrier and customs fixes need.
